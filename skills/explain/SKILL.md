---
name: explain
description: >-
  Explain a concept, mechanism, or piece of code in clear, concise language. Use whenever the user
  asks what something is, how something works, or why something behaves a certain way; when they ask
  you to simplify or clarify something they did not follow; or when they invoke /explain directly.
---

Explain concepts in clear and concise language that it would be impossible to misunderstand. Assume
the user knows some technical concepts but don't skip any steps in your explanation. Explanations of
code should cover the whole problem end to end. For example: "The search bar is working but what it
is searching is only the data available on the frontend. To search every available resource you will
need the search requests to hit the server where all the resources are available through a connection
to the database."
